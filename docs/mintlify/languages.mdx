Coverage varies by detector. JavaScript and TypeScript are full
across all six detectors. Python and Go have fixtures in all six
detectors today, with two scope limits called out below. Ruby is
narrower. Java and PHP are not covered yet.

The authoritative scope (which fixtures exist, what each detector
catches per language) lives at
[`docs/detector-capabilities.md`](https://github.com/tornidomaroc-web/fixor/blob/main/docs/detector-capabilities.md).
This page summarizes.

| Language | Status | Notes |
| --- | --- | --- |
| **JavaScript** | ✅ Full | All 6 detectors |
| **TypeScript** | ✅ Full | All 6 detectors |
| **Python** | 🟡 Partial | All 6 detectors have fixtures. `auth-bypass` and `admin-check` catch their sentinel/hardcoded shapes; their Express-router missing-middleware / missing-admin-gate patterns are JS/TS-only |
| **Go** | 🟡 Partial | Same shape as Python: all 6 detectors have fixtures; route-shape patterns are JS/TS-only |
| **Ruby** | 🟡 Limited | `auth-bypass` and `idor` fixtures only |
| **Java** | 🚧 Roadmap | First-class detectors planned |
| **PHP** | 🚧 Roadmap | First-class detectors planned |

## What "Partial" and "Limited" mean

Per-detector, per-language:

| Detector | JS/TS | Python | Go | Ruby |
| --- | --- | --- | --- | --- |
| `auth-bypass-multi` | ✅ | 🟡 sentinels only | 🟡 sentinels only | 🟡 sentinels only |
| `admin-check-multi` | ✅ | 🟡 hardcoded shapes only | 🟡 hardcoded shapes only | ❌ |
| `idor-multi` | ✅ | ✅ FastAPI | ✅ chi + raw SQL | ✅ Rails |
| `env-exposure-multi` | ✅ | ✅ Flask, FastAPI | ✅ | ❌ |
| `secrets-exposure-multi` | ✅ | ✅ | ✅ | ❌ |
| `webhook-unverified-multi` | ✅ | ✅ Flask | ✅ HandleFunc | ❌ |

The two JS/TS-only patterns are the route-definition shapes:
`auth-bypass`'s missing-middleware case (Express `router.post(...)`
without an auth middleware) and `admin-check`'s missing-admin-gate
case (Express privileged route with no admin check anywhere). These
look at routing structure specifically, and we have not built that
out for Python/Go web frameworks yet.

**Framework-shape caveat within JS/TS.** Next.js App Router method-
named exports (`export const POST = ...` / `export async function
GET(...)`) ARE now covered for those sub-claims via missing-HOC-
wrapper / missing-admin-HOC-wrapper detection. Measured 2026-05-23
against 182 of 228 inbox-zero App Router routes (~80%, PARTIAL scan,
halted for API budget — not a full-corpus sweep): 0 auth-bypass and
0 admin-check findings on the partial 182-route sample, plus 2 webhook findings
of documented-limitation classes (see `detectors.mdx` for the four
scope limitations). Phase F + Path-A structural follow-up (2026-05-23) lifted the cross-
file verifier-helper class (c) and the non-HMAC shared-secret
challenge class (d) from HIGH to MEDIUM/review-queue. Path A
switched the webhook detector to whole-file payload for App Router
route-def triggers (matching auth-bypass / admin-check); both real
inbox-zero routes — outlook/webhook and apple/webhook — now route
to MEDIUM/review-queue with the verify*Payload name-convention
recognized in the full file context. No remaining apple-shape
residual.
Remix v2 `loader` / `action` exports ARE now covered (Phase E,
2026-05-23) for the same three route-shape detectors via a sibling
`REMIX_HANDLER_DEF_RE` and an `isRemixRoutePath` path-aware filter
that bounds over-match to the Remix v2 file-system convention
(`/routes/` segment or `app/root.{ts,tsx}`). Calibration: 17 Remix
fixtures (auth-bypass 6 + admin-check 6 + webhook 5, including
over-match utility anchors), all passed; end-to-end demo on
fixor-demo-remix flagged 3 planted Remix-shape vulnerabilities with
correct detector attribution. **Named residuals at the point of this
claim:** (i) **real-world Remix production-corpus baseline (e.g.
against Trigger.dev's 411 routes) is deferred** — the cheap
calibration + demo were scientifically sufficient under the same
partial-sample discipline that closed Phase D; (ii)
**non-conventional wrapper-name divergence on unknown Remix
codebases is a known residual** until a real corpus is measured —
the path-aware filter bounds (does not eliminate) over-match on
utility modules, and HOC-name coverage is limited to the calibrated
set (`withAuth`, `withAdmin`, `withLogging`, `withSessionAnalytics`,
`requireUser`, `getServerSession`). The content-based sub-claims
(sentinel strings, hardcoded-admin shapes, IDOR, env-exposure,
secrets-exposure including Next.js-aware `NEXT_PUBLIC_*` patterns,
and webhook lib-import / anti-pattern detection) work on
router-style and file-system-routed (App Router, Remix) frameworks
normally. See
[`docs/detector-capabilities.md`](https://github.com/tornidomaroc-web/fixor/blob/main/docs/detector-capabilities.md)
for the per-sub-claim breakdown, the partial-scan caveat on App
Router, and the deferred-baseline caveat on Remix.

Everything else is text-pattern detection that travels across
languages as long as the prefilter regex and the LLM verdict have
been exercised against a fixture in that language.

## What "Roadmap" means

For Java and PHP today, Fixor will not produce useful findings:
neither the prefilters nor the LLM prompts have been tuned for those
languages, and we ship no fixtures to validate them against. Don't
install Fixor on Java or PHP repos expecting accurate output.

The order in which new languages are added is driven by paid-customer
demand. Once three or more paying customers ask for the same
language, it becomes a sprint-sized task: per-detector prefilter
patterns, positive + negative fixtures in that language, and a
baseline stability run.

If a language matters to you, email
<a href="mailto:support@fixor.dev">support@fixor.dev</a> with one
sentence on what your stack looks like. Free-tier requests still
count toward demand signal.

## What we will not add

- **Configuration languages** (YAML / JSON / HCL). Vulnerabilities in
  config are real but the detection shape is structural rather than
  textual; out of scope.
- **Compiled-only languages without source diffs.** Fixor reads the
  diff. No source in the PR, nothing to scan.
- **Proprietary or legally restricted code.** Anthropic's terms
  apply to anything Fixor sends through Claude. Do not install Fixor
  on repositories you are not authorized to share.
