Fixor is a GitHub App that reviews pull request diffs for security
issues and posts a structured report back as a PR comment, with a
downloadable PDF/SARIF attached. Install once on a repo or org, and
every subsequent PR gets the same review within ~30 seconds.

## What you get on every PR

- **Findings + severity** — one row per issue, with the file path,
  line, and a short rationale.
- **Suggested fixes** — concrete patches generated by Claude, not
  regex. Framework-aware: understands Express, Knex, Prisma, raw
  `pg`/`mysql2`, common DOM sinks, and more.
- **PDF + SARIF report** — linked from the comment via a signed URL
  (1-hour TTL). Share the PDF with your team or attach it to a
  compliance ticket.

## Why teams choose Fixor

- **Zero setup.** Install the App. No CI step, no IDE plugin, no
  rule tuning to start.
- **Cost cap built in.** Each org has a hard monthly Anthropic
  budget. Fixor pauses scans before the bill surprises you, with
  an 80% nudge before that.
- **A real dashboard.** Per-org scan history, settings, trends,
  billing — all live at <a href="https://app.fixor.dev">app.fixor.dev</a>.
- **Open source.** MIT-licensed at
  [github.com/tornidomaroc-web/fixor](https://github.com/tornidomaroc-web/fixor).
  Every claim in this documentation is checkable against the
  source.
