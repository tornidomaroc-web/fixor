Fixor is a GitHub App that runs six security checks on pull request
files and posts a structured report back as
a PR comment, with a downloadable PDF/SARIF attached. Install once
on a repo or org, and every subsequent PR gets the same review within
roughly 10 to 30 seconds.

## What has been measured

The hardcoded-secrets check (fixed patterns, no model) is measured on real
code: on 43 customer-shaped repositories it raised 5 flags, 3 of them real
credentials; on 13 mature open-source projects, 15 flags, all false alarms
(2026-09-12). The three access-control detectors (auth bypass, missing admin
gates, IDOR) pass their authored fixtures; on 12 published access-control vulnerabilities in real open-source projects, the shipped pipeline flagged none (field trial, 2026-09-19).
Environment-variable exposure and unverified webhooks have no real-code
result. Detection development stopped on 2026-10-04; the detectors ship as
they are.

## What you get on every PR

- **Findings + severity:** one row per issue, with the file path,
  line, and an explanation (written by Claude for five of the six
  detectors; the secrets check uses a fixed explanation).
- **Remediation steps:** written per finding,
  framework-aware. Fixor reasons about Express routing, auth
  middleware patterns, Prisma/Drizzle ownership scoping, role-guard
  conventions, and env/secret handling.
- **PDF + SARIF report:** linked from the comment via a signed URL
  (1-hour TTL). Share the PDF with your team or attach it to a
  compliance ticket.

## Detectors shipping today

  <Card title="Authentication bypass" icon="lock-open" href="/detectors#authentication-bypass">
    Sentinel-string bypasses across TS/JS/Python/Go/Ruby; missing

  </Card>
  <Card title="Missing admin checks" icon="user-shield" href="/detectors#missing-admin-checks">
    Hardcoded email/role allowlists, client-supplied role reads,
    privileged routes with no admin gate.
  </Card>
  <Card title="IDOR" icon="key" href="/detectors#idor-insecure-direct-object-reference">
    Request-derived ids reaching a database query with no ownership
    filter. Express, Next.js, Fastify, Hono, tRPC, NestJS, FastAPI,
    Rails, Go chi.
  </Card>
  <Card title="Env-variable exposure" icon="leaf" href="/detectors#environment-variable-exposure">
    `process.env` (or Go `os.Environ()`) reaching a response body or
    logger payload.
  </Card>
  <Card title="Hardcoded secrets" icon="shield-keyhole" href="/detectors#hardcoded-secrets">
    Literal API keys, signing secrets, Postgres URLs, `NEXT_PUBLIC_*`
    server secrets reaching the client bundle.
  </Card>
  <Card title="Unverified webhooks" icon="webhook" href="/detectors#unverified-webhook-handlers">
    Webhook handlers that skip signature verification. Stripe,
    GitHub, Twilio, Slack, Lemon Squeezy, custom HMAC.
  </Card>
</CardGroup>

The authoritative scope contract (what each detector catches and

The [detector catalogue](/detectors) page summarizes it. When in
doubt, the capabilities file wins.

## Why teams choose Fixor

- **Zero setup.** Install the App. No CI step, no IDE plugin, no
  rule tuning to start.
- **Cost cap built in.** Each org has a hard monthly Anthropic
  budget. Fixor pauses scans before the bill surprises you, with
  an 80% nudge before that.
- **A real dashboard.** Per-org scan history, settings, trends,
  billing, all live at <a href="https://app.fixor.dev">app.fixor.dev</a>.
- **Open source.** MIT-licensed at
  [github.com/tornidomaroc-web/fixor](https://github.com/tornidomaroc-web/fixor).
  Every claim in this documentation is checkable against the
  source.
